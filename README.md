# 🚛 Frota+

### Gestão financeira inteligente para caminhoneiros e pequenas frotas

O **Frota+** é um sistema web desenvolvido para simplificar o controle financeiro de caminhoneiros autônomos e pequenas frotas, substituindo anotações em papel por uma plataforma digital prática, organizada e eficiente.

A proposta é centralizar as informações da operação em um único lugar, permitindo acompanhar viagens, abastecimentos, despesas e resultados financeiros com mais clareza e precisão.

---

## 🎯 Objetivo do projeto

Facilitar a gestão financeira do transporte rodoviário, ajudando caminhoneiros a compreender seus custos operacionais, calcular a rentabilidade das viagens e tomar decisões mais conscientes sobre suas atividades.

## ⚙️ Funcionalidades

- 🚚 **Gestão de caminhões:** cadastro e organização dos veículos.
- 🛣️ **Controle de viagens:** registro de quilometragem, fretes e viagens carregadas ou vazias.
- ⛽ **Abastecimentos:** controle de diesel e Arla, com estimativa de consumo.
- 🧾 **Controle de despesas:** registro de pedágios e outros custos operacionais.
- 💰 **Análise financeira:** cálculo do lucro, prejuízo e custo por quilômetro rodado.
- 📊 **Dashboards e relatórios:** acompanhamento de receitas e despesas por semana, mês e ano.
- 🔐 **Gestão de usuários:** autenticação e separação dos dados de cada usuário.

## 💡 Diferencial

O Frota+ considera situações reais da rotina dos caminhoneiros, como abastecimentos parciais, abastecimentos com tanque cheio e viagens realizadas sem carga.

Com base nos registros disponíveis, o sistema poderá estimar o consumo médio de combustível e o custo de cada viagem, mantendo o controle dos gastos reais com abastecimento separado das estimativas de consumo.

Dessa forma, o usuário terá uma visão mais clara da rentabilidade de cada operação e dos custos envolvidos em sua atividade.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|:--|:--|
| **Angular** | Desenvolvimento da interface web |
| **Java** | Linguagem do back-end |
| **Spring Boot** | Construção da API REST |
| **Spring Data JPA** | Persistência e acesso aos dados |
| **PostgreSQL** | Banco de dados relacional |
| **Spring Security + JWT** | Autenticação e segurança planejadas |

## 📈 Resultados esperados

- Maior organização financeira.
- Controle centralizado das viagens e despesas.
- Melhor compreensão dos custos por quilômetro.
- Identificação da rentabilidade de cada viagem.
- Apoio à tomada de decisões financeiras.
- Redução da dependência de controles manuais.
